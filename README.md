AI RESEARCH ASSISTANT

This is an industry-inspiration LOCAL AI Reseach Assistant Using Ollama, FAISS and LangGraph
A project mainly focused on building a good understandaing on how LLM systems are constructed reasonably.

LLM - Qwen3:4b
Embedding Model - nomic-embed-text
Framework - LangChain
Agent Framework - LangGraph
Vector Database - FAISS
Dataset - SQuAD (from HuggingFace)
Runtime - Ollama 
Language - Python 

PROJECT STATUS:
Browser > Streamlit UI > HTTP request > FastAPI > ResearchAgent > Langraph - Tool Node, Retrieval Node > LLM > Response

AI Layer - Ollama, Qwen3, nomic-embed-text, RAG, FAISS
Agent Layer - LangGraph, ReAct, Tool Registry, LLM based routing

Backend - FastAPI, Pydantic Schema

Frontend - Streamlit
